# 세션회고 모드

목적: 이번 대화에서 생긴 "다음에도 반복 적용할 규칙"을 놓치지 않고 프로필·스킬에 쌓는 것. 업무일지처럼 무엇을 했는지 적는 게 아니라, **다음 대화의 Claude가 다르게 행동해야 할 점**만 뽑는다.

## 1. 절차
1. 대화 전체를 처음부터 훑는다. 특히 사용자가 Claude 답을 고치거나 거절한 지점, "앞으로는", "항상", "이건 빼" 같은 표현을 찾는다.
2. 아래 6유형으로 후보를 뽑는다.
3. 제외 기준으로 거른다.
4. 기존 프로필·스킬과 비교해 관계(신규/수정/충돌)를 정한다. 프로필·스킬 원문을 볼 수 없으면 관계는 [추정]으로 적는다.
5. 후보표를 제시하고 멈춘다.

## 2. 추출 6유형
| 유형 | 찾는 것 | 예 |
|---|---|---|
| ① 교정 | 사용자가 Claude 답을 바로잡은 사항 | "억원 말고 천원으로" |
| ② 형식 선호 | 산출물 구조·표기 방식 | "검토 결과는 표 먼저" |
| ③ 사실·기준값 | 회사 정보, 기준일, 수치 변동 | 연결 범위 변경, 담당자 변경 |
| ④ 절차·도구 | 스킬 오호출, 환경 제약, 도구 사용 요령 | "클라우드 세션은 외부 이미지 도메인 차단" |
| ⑤ 판단 기준 | 반복 적용할 판단 원칙 | "개발 전용 도구는 업무 연관성 없음으로 분류" |
| ⑥ 미결 | 결론 나지 않은 것 | 규칙화하지 않고 handoff 이관 |

①은 가장 가치가 크다 — 사용자가 같은 교정을 두 번 하게 만드는 것이 이 스킬이 막으려는 핵심 문제다. 교정이 있었다면 반드시 후보에 넣는다.

## 3. 제외 기준
- 이번 대화에만 해당하는 일회성 지시("이번 표는 3열로")
- 이미 프로필·스킬에 같은 내용이 있는 것(중복) — 단, 있는데도 Claude가 어겼다면 "준수 실패" 메모로 따로 적는다(규칙 추가가 아니라 기존 규칙 강화 후보)
- Claude가 추론만 하고 사용자가 확인하지 않은 것 → 넣더라도 [추정]·기본 비권고로 표시
- 공시 전 정보 원문, 개인정보, 계정·비밀번호

## 4. 후보표 양식 (최대 7개)
| 번호 | 유형 | 규칙(1줄, 명령형) | 근거(발언 인용 또는 시점) | 반영처 | 관계 | 확신도 |
|---|---|---|---|---|---|---|

- 규칙은 다음 대화의 Claude가 그대로 따를 수 있게 1줄 명령형으로 쓴다. "~하면 ~한다".
- 7개를 넘으면 우선순위(① > ③ > ⑤ > ② > ④) 순으로 자르고 나머지는 "생략 후보" 한 줄 목록으로 붙인다.
- 같은 반영처에 비슷한 규칙이 3건 이상이면 통합 문안을 함께 제안한다.
- 충돌 항목은 표 아래에 "기존: … / 신규: …"로 나란히 보여준다.

## 5. 표 뒤에 붙일 것
- 승인 요청 1줄: "반영할 번호를 알려주세요(예: 1, 3). 충돌 항목 N번은 개별 확인이 필요합니다."
- ⑥ 미결이 있으면 "handoff 이관 목록" 별도 표기.
- 후보가 하나도 없으면 억지로 만들지 말고 "이번 대화에서 반영할 규칙 없음"과 그 이유를 한 줄로 쓴다.
