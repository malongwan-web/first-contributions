## 1. 요약

- unslop은 Claude Code·Codex용 무료 스킬로, AI가 만든 듯한 UI를 디자이너가 다듬은 화면으로 고쳐 줌 [원문 대조]
- 진행 순서: 문제 신호 점검(Audit) → 디자인 방향 제안 → 단계별 수정(Pass). 수정하기 전에 방향을 먼저 제안하므로 사용자가 초기에 방향을 조정할 수 있음 [원문 대조]
- 점검 신호: 10개 분류, 총 64개 [원문 대조: `references/signs.md`의 항목 수를 직접 집계]
- 라이선스: CC BY 4.0. 상업적 이용 가능, 제작자 표기와 저장소 링크 필요 [원문 대조]

## 3. 점검 신호 분류 (10개 분류, 64개 항목)

| 분류 | 대표 신호 → 수정 방향 |
|---|---|
| 표면·색상 | 보라→파랑 그라데이션 → 중립 배경 1개, 강조색은 의미가 있는 곳에만 |
| 타이포 | 굵기 800~900 제목 → 400~500, 위계는 크기로 표현 |
| 아이콘 | 이모지 내비 아이콘(🏠🚀💰) → 선형 아이콘 세트 1종으로 통일하거나 제거 |
| 간격 | `mt-[13px]` 같은 임의값 → 4px 단위 스케일 |
| 문구 | `Welcome back, Damir! 👋` 같은 인사형 제목 → 페이지명이나 기간을 제목으로 |
| 컴포넌트 | 개수·요금제·상태를 표시하는 빛나는 알약형 배지 → 차분한 모노 텍스트나 키캡 |
| 랜딩·히어로 | 제목 위 `✨ Introducing X 2.0` 배지 → 제거하거나, 실제 소식이면 차분한 텍스트 링크 |
| 비주얼 | 광택 있는 3D 블롭·구체·보라색 성운 히어로 → 제품 화면 그 자체 또는 구체적 은유 1개 |
| 모션 | 실시간 데이터가 아닌데 붙인 `animate-pulse`·`animate-ping` → 정적 표시 |
| 템플릿 느낌 | 제품 이름만 바꾸면 다른 제품에도 쓸 수 있는 헤드라인 → 그 제품만의 명사로 하는 일을 설명 |

- 위 10개 분류의 예시는 각 분류에 실린 원문 항목을 번역·요약한 것 [원문 대조]
- '템플릿 느낌' 분류는 원문에서 "slop은 아니지만, 아무도 결정을 내리지 않았을 때 정리된 화면이 되돌아가는 모습"으로 정의되며, 단계별 수정을 마친 뒤 점검하는 항목

## 4. 설치 및 사용 [원문 대조]

### 설치 (Claude Code)

```bash
git clone https://github.com/heydamir/unslop
mkdir -p ~/.claude/skills && cp -r unslop/skills/unslop ~/.claude/skills/
```

- 특정 프로젝트에서만 쓰려면 해당 프로젝트의 `.claude/skills/`에 복사
- 라이브 사이트 스냅샷이나 비포/애프터 영상을 만들려면 추가 설치 필요:

```bash
npm install -D playwright
npx playwright install chromium
# 그 외 ffmpeg를 설치하고 PATH에 등록
```

### 사용 예시

```
/unslop this dashboard
/unslop the hero of https://example.com
/unslop my landing page and make the story video so I can post it
```

- 지원 스택: Next.js, React, Vue, Svelte, Tailwind, 순수 HTML·CSS
- 지원 대상: 대시보드, 앱, 랜딩 페이지, URL만 있는 라이브 사이트
- 이미 잘 만든 화면이면 전면 재설계 대신 작은 개선점만 제안
- 실습용 예제: 저장소의 `examples/dashboard.html`, `examples/hero.html`

## 5. 유의 사항

- 유료 이미지 생성: 히어로 이미지가 필요하면 fal, Replicate, OpenAI images 등 외부 서비스를 MCP로 연결해 생성. 유료 생성 전에는 매번 프롬프트를 보여 주고 승인을 받음 [원문 대조]
- 외부 전송: 라이브 사이트 스냅샷 스크립트(`scripts/snapshot.mjs`)는 대상 URL과 스타일시트를 내려받음. 사내 미공개 화면을 외부 이미지 서비스에 넘기지 않도록 주의
- 버전 차이: 64개 항목 수와 9단계 순서는 2026.11.01 커밋 기준. 업데이트되면 달라질 수 있음
- 라이선스: 수정본을 배포할 때는 CC BY 4.0에 따라 제작자 표기와 저장소 링크를 반드시 남겨야 함
